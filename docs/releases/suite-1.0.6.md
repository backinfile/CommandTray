# CommandTray Suite 1.0.6

- 画板新增抓手、以指针为中心缩放、适应内容、重置视图和可撤销的清空操作。新增菱形、荧光笔、对象复制和层级调整，PNG 导出包含整张画板。
- 剪贴板历史可编辑后发送，也可把文本带入实用工具。共享文件支持复制名称和 SHA-256，Windows 截图及录屏可直接加入共享文件上传队列。
- 实用工具新增本地文件校验、文本对比、Unix 秒／毫秒与 ISO 8601 转换，以及二维码 PNG 导出。文件校验可从共享文件直接带入预期 SHA-256。
- 文本转换支持 JSON 格式化和压缩、Base64 和 URL 组件编解码、按行去重及文本 SHA-256。
