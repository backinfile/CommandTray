# 合并套件修复并更新中转

## 用户要求

> 全部修复合并，清理分支，重新部署服务器，中转服务器你用版本号来匹配客户端，只中转支持的版本号

## 计划

合并已完成的工作区与 Web 修复。Windows、Linux、Android 和内置 Web 统一发送套件版本，中转仅接收明确支持的版本。验证发布产物和中转版本校验后，部署到现有服务，清理已合并且工作区干净的功能分支。

## 改动与验证

- 工作区修复包括待办勾选对齐、卡片内新增待办、组件弹窗、画板工具栏和 Windows MCP 空间导航。Web 同步冲突保留草稿，剪贴板保留置顶原文。
- 中转默认匹配自身版本，也支持配置准确版本名单。请求缺少版本或版本不受支持时返回 HTTP 426。使用有效凭据也须通过版本校验。
- 以 1.0.1 构建 Windows 和中转。通过中转版本边界、Web 版本注入、Windows MCP 配对及工作区同步测试。
