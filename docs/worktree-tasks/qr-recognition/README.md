# 二维码、工具导航与桌宠

## 用户输入

> 有二维码识别吗？你看看其他功能，搜搜同类项目补充功能。然后找找有没有还有可以添加的方便工具功能

> 另外你需要根据这些工具的领域来分组（在左侧页签分组，而非全部折叠起来）， 你来制作一个导航页，显示所有工具

> 宠物功能和图片都不够好，继续找参考制作

> 合并推送 清理分支 重新部署 重新安装到本地

## 结果与发布

- 二维码图片和摄像头识别、工具导航、桌宠及相关操作记录在 [1.0.7 变更说明](../../releases/suite-1.0.7.md)。后续候选和参考资料见 [实用功能调研](../../suite-utility-research.md)。
- Windows 无界面检查验证了本地识码、截图入口、文本工具、工具总览和桌宠姿态。Web 浏览器检查验证了本地识码、模拟摄像头及其释放、窄屏导航和添加工作区组件。
- 从 `codex/suite-dev` 发布套件，核验签名更新清单与两个部署包的 SHA-256，再更新 Windows 安装及中转服务。
